# Дымковская мастерская

Мобильная мастерская росписи игрушек. Сайт в корне работает на GitHub Pages без сервера; профиль и игрушки хранятся в браузере устройства. Полные исходники серверной версии находятся в source.zip. Для синхронизации аккаунтов нужен сервер и настройка авторизации; GitHub Pages не выполняет API.

AR требует совместимого телефона, HTTPS и разрешения камеры.
